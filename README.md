# 记忆的气味 · Scent of Memory

一个将气味、个人记忆与情绪表达连接起来的交互式网页作品。项目以“普鲁斯特效应”为概念起点，通过弥散渐变、有机形态和轻量动画，将难以描述的情绪转化为可选择、可保存、可筛选的视觉信息符号。

**在线体验：** https://scent-memory-yuqi.genialllama14.chatgpt.site

## 项目背景

气味常常会在没有预告的情况下唤起一段记忆。本项目尝试回答一个设计问题：如果气味能够唤醒记忆，是否可以通过视觉符号帮助人们记录和理解记忆中的情绪？

项目由视觉传达设计出发，将原创情绪符号系统进一步转化为真实可运行的数字产品原型。

## 核心设计

- **12 种弥散式情绪符号**：安心、快乐、平静、愤怒、紧张、忧伤、怀念、期待、温暖、惊喜、遗憾和孤独。
- **统一视觉语言**：使用 SVG 渐变、半透明图层、柔焦边缘与有机轮廓表现情绪的流动性。
- **克制的动态反馈**：不同情绪具有呼吸、漂浮、脉动或收缩等选中动画，并支持系统的“减少动态效果”设置。
- **响应式体验**：适配桌面端与移动端，并提供键盘操作和清晰的选中状态。

## 已实现功能

- 创建气味记忆并选择对应情绪
- 将新增记录生成可浏览的记忆卡片
- 按气味类别或情绪进行筛选
- 搜索标题、故事、气味与情绪
- 共鸣、给予温暖、收藏和分享记忆
- 刷新页面后保留个人记录与操作状态
- 兼容早期版本的情绪数据

## 隐私与数据

用户新增的记忆、收藏和互动状态仅保存在其浏览器的 `localStorage` 中。不同访问者之间不会共享记录，私人内容也不会上传到公共服务器。

## 技术实现

- HTML5
- CSS3 / Responsive Design / CSS Animation
- Vanilla JavaScript
- SVG Gradients and Filters
- Browser Local Storage

项目没有第三方依赖，不需要安装环境或配置数据库。

## 本地运行

直接在浏览器中打开 `index.html` 即可使用。为了获得更稳定的本地存储与剪贴板体验，也可以在当前目录启动任意静态文件服务器。

## 部署

仓库根目录中的 `index.html` 可以直接部署至 GitHub Pages、Netlify、Vercel 或 Cloudflare Pages。
